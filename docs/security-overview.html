For managers

Priority Assistant

What it is, what it can see, and where its data is kept.

Version 0.1.2  ·  November 18, 2026  ·  Made by Group 11 (Caleb Kitt, Caleb Waite, Elise Valentic), a student class project

What it is

Priority Assistant is a browser extension for Gmail and Outlook on the web (Chrome, Edge, Brave, Opera or Vivaldi), with an optional phone web app. It learns how the person already handles email (what they answer first, forward, ignore and file where) and ranks the inbox the same way, with top priorities, next steps and reminders in a sidebar. Once its guesses match the person's choices often enough, it can file routine email into folders, with undo.

What we're asking: allow the employee to install the extension in their work browser and connect their work mailbox for the test period. If your company restricts browser extensions or third-party apps, page 2 has what IT needs.

What it can access

  • Email in the connected mailbox: read it, label or categorize it, move it, put it in Trash, and send it when the person presses Send.
  • One app-only folder in that account's Google Drive or OneDrive. No other files.
  • The person's name and email address.
  • It runs only on Gmail and Outlook web pages, not on any other site.

Where data is kept

Employee's browser or phoneSign-in tokens, settings, recent email details (sender, subject, preview) and what it learned. All sorting runs here.
Their own Drive or OneDrive app folderWhat it learned (senders, folders, reminders, settings), so computer and phone stay in sync. Not full email text.
Team relay (Cloudflare)Passes sign-in requests through, and AI requests if AI is on. Stores nothing.
Google GeminiOnly if the person turns AI features on (see below).

We run no database, and no one on the team can see anyone's email.

Safeguards

  • It never sends on its own. It also asks again before forwarding attachments, money or bank details, email outside the company, or anything to more than five people.
  • Automatic filing has to earn trust. It waits until its guesses match the person's choices 85% of the time, never files away anything that looks important, and every move can be undone.
  • Nothing is permanently deleted. Trash goes to Gmail's Trash or Outlook's Deleted Items.
  • Standard sign-in. Google's and Microsoft's own sign-in pages (OAuth 2.0 with PKCE). The app never sees passwords, and access can be revoked at any time.
  • No downloaded code. Everything it runs is in the package the employee installs.
  • No ads and no selling data. We don't train AI on anyone's email.

AI features: off by default

With AI off, no email text goes to any AI service, and sorting, learning and filing still work. If the person turns AI on, the text of the emails being summarized or answered goes to Google's Gemini. The team's key is a paid key, so Google doesn't use that text to train its AI. The same goes for a company's own paid key; only a free personal key would let Google use it to improve its AI.

Where it stands

This is a student project in early testing, with no independent security audit or certification such as SOC 2. It isn't in the Chrome Web Store, so it's installed in Developer mode and updated by hand. Google hasn't verified it (that takes a paid security assessment), so a warning appears at sign-in and it's limited to 100 Google users. Like other extensions, it keeps sign-in tokens in the browser, and revoking access cancels them.

Allowing it

Managed Chrome or Edge

Testers install it with Developer mode and "Load unpacked." If policy blocks that, or blocks extensions not on an allow list, allow the extension ID above.

Microsoft 365 (work or school)

If the employee sees "Need admin approval," an admin connects Outlook in the extension once and ticks "Consent on behalf of your organization." You can later limit or remove it under Enterprise applications in the Entra admin center.

Google Workspace

  1. Admin console → Security → Access and data control → API controls.
  2. Manage Third-Party App Access → add an app by OAuth client ID, and paste the Google client ID above.
  3. Choose which users it applies to and set it to Trusted.

Menu names change from time to time. Google's help article "Control which third-party & internal apps access Google Workspace data" has the current steps.

Removing it

  1. Disconnect the account in Priority Assistant's Settings, then remove the extension. On a phone, clear the app's site data.
  2. Revoke access at myaccount.google.com/permissions (Google), myapps.microsoft.com (Microsoft work or school) or account.live.com/consent/Manage (Microsoft personal).
  3. Delete the app folder: Google Drive → Settings → Manage apps → Priority Assistant → Delete hidden app data, or OneDrive → Apps → Priority Assistant.

Priority labels or categories the app added stay in the mailbox until someone deletes them.
